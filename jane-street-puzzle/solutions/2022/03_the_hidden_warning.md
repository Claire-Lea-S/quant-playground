# The Hidden Warning - March 2022 (Solution)

**Puzzle:** [03_the_hidden_warning.md](../../puzzles/2022/03_the_hidden_warning.md)

## Official Solution

Many of the clues admitted answers that sounded like groups of letters of the alphabet, and these letters came in alphabetic order:

| Clue | Answer |
|------|--------|
| Early stage of an animal | BABY |
| Early stage of a plant | SEED |
| Creepy | EERIE |
| Reviled image that might fire up a crowd? | EFFIGY |
| In minesweeper, it means you're surrounded | EIGHT |
| Spiced brew | CHAI |
| Tapper on CNN | JAKE |
| Iron or Bronze | AGE |
| Iron but not bronze | ELEMENT |
| Boy on "The Andy Griffith Show" | OPIE |
| Signal | CUE |
| Suspect, once apprehended | ARRESTEE |
| "__ got mail" | YOUVE |
| Raise the stakes yet again, in backgammon | REDOUBLE |
| First mammal to be cloned | EWE |
| Outer: prefix | EXO |
| With consideration | WISELY |

The extra sounds that only occurred in the answer list spelled out the answer when sounded out consecutively:
**B**ABY, EE**R**IE, EFF**I**GY, A**GE**, ELEMEN**T**, YOUVE **R**EDOUBLE, EX**O**, WISE**L**Y

**Answer: BRIDGE TROLL**
