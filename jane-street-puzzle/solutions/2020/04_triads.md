# Triads - April 2020 (Solution)

**Puzzle:** [04_triads.md](../../puzzles/2020/04_triads.md)

## Official Solution

**Answer: 284**

All numbers congruent to 0, 2, 9, or 11 mod 12 are able to be constructed, and no others are.

The arrangements for N = 2, 9, 11, and 12 can be constructed. We can then add 12 rows to any of these 4 triangle sizes by adding an N=12 triangle, and a 12-by-N parallelogram, below them.

This problem was investigated by John Conway. The valid values are: 2, 9, 11, 12, 14, 21, 23, 24, 26, 33, 35, 36, 38 (sum = 284).
