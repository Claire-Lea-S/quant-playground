# Expelled - May 2020 (Solution)

**Puzzle:** [05_expelled.md](../../puzzles/2020/05_expelled.md)

## Official Solution

The bottom grid displays, for each number 1 through 10, the number of the row where it is eventually expelled.

**Answer: 416**

It is not until row 416 that the number 11 is finally expelled!
