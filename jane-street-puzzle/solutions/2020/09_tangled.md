# Tangled! - September 2020 (Solution)

**Puzzle:** [09_tangled.md](../../puzzles/2020/09_tangled.md)

## Official Solution

The fastest sequence of untangling the ropes found was this 114-command solution:

```
RSSSSRSSRSSRSSRSSRSSRSSRSSRSSRSSRSSRSS
RSSRSSRSSRSSSSSRSSRSSRSSSRSSRSSSSRSSRS
SRSSSSRSSRSSRSSRSSRSSRSSSRSSSRSSRSSRSS
```

It could be discovered by using the theory of *rational tangles*, which maps ropes tangled by these commands onto rational numbers using continued fractions. The late John H. Conway of puzzle math fame worked on this, hence the silly name for the dance "Yawn-ock" ("Conway" is hidden in there backwards).

The fastest sequence found was **114** commands.
